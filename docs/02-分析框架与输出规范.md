# 02 · 分析框架与输出规范（做多/做空硬逻辑）

> 目标：把 **rank20（主力合约 20 日涨跌幅排名）** 变成**可证伪的硬逻辑**，而不是技术形态猜测。
> 核心立场：**涨跌幅只是结果，不是原因**。任何一条结论都必须能落到"驱动因子 + 可观测证据 + 确认日 + 失效条件"。

## 需求边界（D4，见 `04-总设计.md §0.1`）

| 项 | 规定 |
| --- | --- |
| **分析对象** | **仅 D1 的 rank20 品种集合**（涨幅前 20 + 跌幅前 20）；不在榜内的品种不产出逻辑 |
| **数据来源** | **不设具体数据要求** —— 允许灵活取材（资讯、产业数据、持仓排名、仓单、人工判断等任意可用来源） |
| **字段完整度** | **不要求达标**。本文档列出的证据字段（基差/库存/仓单/月差等）为**建议性可选增强**，缺失不构成阻塞 |
| **唯一硬约束** | 输出的硬逻辑必须**指向 rank20 品种**，且符合 §6 的结构规范与 §0 的四要素 |

> 换句话说：**rank20 是"必须做对的题"，因果分析是"尽力做好的题"。**

---

## 0. 硬逻辑的定义（写进 Agent 的 system prompt）

一条合格的"做多/做空硬逻辑"必须同时具备四个要素，缺一即降级为"观察"：

| 要素 | 含义 | 反例（不合格） |
| --- | --- | --- |
| **驱动 (Driver)** | 四类源头之一：供给冲击 / 需求冲击 / 库存物流约束 / 政策宏观 | "MACD 金叉" |
| **证据 (Evidence)** | ≥2 个可观测字段同向（持仓、仓单、基差、月差、板块广度） | "感觉要涨" |
| **确认日 (Confirm)** | 某日满足 ≥3 条确认规则，给出具体日期 | "随时可能启动" |
| **失效 (Invalidate)** | 明确写出什么信号出现就作废 + 阈值 | "长期看好" |

**归因纪律**：一手（交易所/部委原文）> 行业协会 > 商业资讯 > 媒体转述。硬逻辑必须能附带可点击的一手 URL。

## 1. 因果链五层模板

```
L0 事件     矿山事故 / 政策文件 / 装置检修 / 出口配额 / 天气
   ↓
L1 驱动     供给收缩预期 | 需求扩张预期 | 库存约束 | 宏观流动性
   ↓
L2 传导     库存去化 / 开工率下降 / 利润压缩 / 进口窗口关闭
   ↓
L3 结构     基差走强、近月升水（Back 加深）、月差走强
   ↓
L4 盘面     龙头领涨 → 板块扩散（广度）
   ↓
L5 资金     持仓量增加 + 仓单减少 + 前20净持仓同向
```

**实例（可对照真实行情）**：
`矿山事故 → 供给收缩预期 → 港口铁矿去库 + 现货挺价 → 基差走强/近月升水 → 铁矿领涨、螺纹跟涨 → 铁矿持仓增 + 仓单减`

### 驱动 vs 跟随 的判别（关键）

| | 驱动 (driver) | 跟随 (follower) |
| --- | --- | --- |
| 与事件的关系 | 事件的**直接对象** | 间接受益/替代品 |
| 时间 | 事件日**先动** | 滞后 0–3 日 |
| 幅度 | 领涨领跌 | 递减 |
| 自身基本面 | 库存/利润同步变化 | 无自身变化 |

> **反例警告**：若"跟涨者先动、龙头未动" → 只是**情绪扩散**，不构成硬逻辑（本次实测 2026-09-16 能化板块集体走强，就属于必须先判定"原油是驱动还是能化内部品种是驱动"的场景）。

## 2. 硬证据字段字典（看多 / 看空含义）

> **定位（D4）**：本节是**建议性可选增强**，不是硬性数据要求。
> 有则更强，缺则用其他可用来源替代（资讯、人工判断等），**不阻塞分析产出**。
> 其中 **① 持仓量变化** 与 **② 前20净持仓** 已可从官方源免费获取，建议优先接入。

**推荐（非必需）的最小证据集：**

| 字段 | 来源 | 看多含义 | 看空含义 |
| --- | --- | --- | --- |
| **持仓量变化 OpI** | 官方日报 / 新浪日K `p` | 价涨**仓增** = 新多进场（真突破） | 价涨**仓减** = 空头回补（假突破）；价跌仓增 = 新空进场 |
| **前20会员净持仓** | 交易所每日持仓排名 | 净多扩大 | 净空扩大 |
| **注册仓单** | 交易所仓单日报 | 注销/减少（现货被拿走） | 大增（卖出套保、过剩） |
| **交易所库存** | 交易所库存周报 | 去库 | 累库 |
| **基差 (现货−期货)** | 产业资讯（Mysteel/卓创/SMM） | 走强、现货升水扩大 | 走弱（盘面虚涨，不被现货承认） |
| **月间价差 (近−远)** | 同日各月份合约（官方日报自带） | Back 加深（近月紧张） | Contango 加深（远端过剩） |
| **进口利润 / 内外比价** | 产业资讯 | 进口亏损 → 进口减少 | 进口窗口打开 → 供给增加 |
| **加工利润** | 产业资讯（钢厂/榨利/PTA） | 利润压缩 → 减产预期（**反向指标**） | 高利润 → 远端复产（**利空远月**） |
| **开工率 / 产能利用率** | 产业资讯 | 下降 = 供给收缩 | 上升 = 供给宽松 |
| **社会库存** | 钢联/卓创 | 去库 | 累库 |

> **落地顺序建议**：① 持仓量（官方日报，零成本）→ ② 前20净持仓（SHFE `pm*.dat`，已通）→ ③ 月间价差（官方日报自带，零成本）→ ④ 基差/库存（需产业源，按需接入）。
>
> **实测补充**：东方财富**日 K 不含持仓量**，但官方日报与新浪 `getDailyKLine` 都带持仓量。**优先用官方日报。**

## 3. 板块划分与龙头判定

### 3.1 板块 → 品种映射（Agent 静态表）

| 板块 | 核心品种 | 龙头 | 核心锚 |
| --- | --- | --- | --- |
| 黑色/建材 | 螺纹、热卷、铁矿、焦煤、焦炭、硅铁、锰硅、玻璃、纯碱 | **螺纹 / 铁矿** | 地产基建 + 钢厂利润 |
| 有色 | 铜、铝、锌、镍、锡、氧化铝、工业硅、碳酸锂 | **铜 / 铝** | 全球宏观 + 库存 |
| 能化 | 原油、燃油、沥青、PTA、乙二醇、甲醇、PP/PE/PVC、苯乙烯、橡胶、瓶片、短纤、纯苯、丙烯 | **原油 / 纯碱** | 原油成本 + 装置检修 |
| 油脂油料 | 豆粕、豆油、棕榈、菜油、菜粕、豆二 | **棕榈 / 豆粕** | 产地天气 + 进口到港 |
| 软商品 | 白糖、棉花、棉纱、苹果、红枣、花生 | — | 天气 + 消费 |
| 农产品 | 玉米、淀粉、鸡蛋、生猪 | — | 养殖利润 + 存栏 |
| 贵金属 | 金、银 | **金** | 实际利率 + 避险 |
| 集运 | 欧线集运 | — | 运价指数 |

### 3.2 龙头量化判定（LeaderScore）

```
LeaderScore = 0.4 × 持仓量分位
            + 0.3 × 成交额分位
            + 0.2 × 板块领先度        # 与板块指数日收益的领先1日滚动相关(60日)
            + 0.1 × 沉淀资金分位
```

- **禁用"涨幅第一"判定龙头** —— 涨幅第一常是硅铁、纯碱、菜籽这类**高弹性小品种**（本次实测榜首 `RS709 菜籽 +13.89%` 仅成交 **1 手**，典型噪声）。
- 硬门槛：板块异动日中，龙头需在 **≥60% 的样本日**率先或同步变动。

**这张榜本身就是因果分析的输入**：
- **能化板块集体走强**（瓶片/甲醇/乙二醇/沥青/短纤/丁二烯胶/纯苯/苯乙烯/PP 共 9 个品种同向）→ 典型**板块共振**，须判定 L1 驱动是原油成本还是装置检修；
- **跌幅侧是"农产品+黑色建材"分散下跌**（生猪/玻璃/PVC/苹果/鸡蛋/纯碱/棉花），**无单一共振源** → 更可能是各自基本面，而非系统性利空；
- **贵金属（沪银 +2.2%）独立走强** → 按"宏观/避险"链条单独归因，不与能化混谈。

## 4. 确认日（Confirmation Day）规则

**确认日 = T 日收盘同时满足以下 ≥3 条。**

| 套件 | 规则 | 可编码阈值 |
| --- | --- | --- |
| **A 结构+量仓** | 突破 20 日高点 / MA20 / MA60 | 持仓量增幅 ≥ 近 20 日均值 **+1.5σ**（或 ≥3%）；成交额 ≥ 20 日均值 **×1.5**；次日收盘仍在突破位之上 |
| **B 板块共振** | 板块内 ≥60% 品种（样本 ≥5）同向；板块指数创 20 日新高；LeaderScore 首位涨幅居板块前 30% | 广度阈值 60% |
| **C 现货共振** | 基差走强方向与盘面一致；近远月价差同向；仓单减少/注销 | 基差变化 > 0 且同向 |
| **D 资金确认** | 前20净持仓与价格同向扩大 | 连续 **2 日** |

- 复评周期：每 **10 个交易日**重评一次，或触发失效信号即终止。
- 依据：道氏理论的"相互验证"原则 —— 单一维度不构成确认。

## 5. 失败 / 证伪条件（Agent 必须主动喊停）

| 失效信号 | 判定 | 处理 |
| --- | --- | --- |
| **价涨仓减**（连续 2 日） | 空头回补而非新多 | 降级为"跟随" |
| **龙头掉队**（板块涨、龙头收跌或滞涨 >2 日） | 行情尾声 | 减仓/移出观察 |
| **基差走弱** | 现货不认盘面 | 逻辑动摇 |
| **Back 转 Contango** | 紧张缓解 | 多头逻辑减弱 |
| **仓单由减转增 / 库存转累** | 供给回归 | 多头逻辑失效 |
| **前20净持仓转空** | 资金反向 | 直接作废 |
| **事件反转**（复产、政策落地、进口放开、辟谣） | 驱动消失 | 直接作废 |

**止损双轨**：
- 价格轨：跌破确认日 K 线低点或 MA20；
- 逻辑轨：价格未破但**证据链断裂** → 从"驱动"降级为"跟随"（不必立刻平仓，但必须改标签）。

## 6. 每日输出的结构化规范（供前端展示）

> **输入已定**：主输入是 `主力合约 20 日涨跌幅 rank20`（与文华「主力合约报价」一致，见 `04-总设计.md §3.5`），
> 即 agent 看到的是**近 20 个交易日的强弱格局**，而非单日噪声。这恰好更适合做因果归因：
> **单日涨跌多属噪声，20 日排名才反映资金与基本面的持续作用。**
>
> **分析范围**：仅限 rank20 品种；**数据来源不限**（D4 不设要求）。

Agent 每个交易日盘后产出如下结构（JSON 形态，前端直接渲染）：

```jsonc
{
  "date": "2026-09-16",
  "session": "closed",            // intraday | closed
  "rankings": {
    "pct20_gainers": [ { "rank":1, "variety":"sc", "name":"原油", "main_contract":"sc2611",
                         "pct_20d":43.4, "pct_1d":8.00, "rolled_over":true } ],
    "pct20_losers":  [ /* 同上 */ ],
    "pct1d_gainers": [ /* 当日榜，作为"加速度"参考 */ ]
  },
  "themes": [
    { "theme":"能化", "direction":"long", "breadth":"9/14",
      "leaders":[{"code":"sc2611","leader_score":0.82}],
      "driver":"装置检修+原油成本抬升",
      "evidence":["20日榜前20中有9个能化品种","MA 持仓增 3.2%","基差走强"],
      "confirm_date":"2026-09-15", "confidence":"high" }
  ],
  "logics": [
    { "id":"L-20260916-01", "product":"ma", "direction":"long",
      "driver":"...", "evidence":[...], "confirm_date":"...",
      "invalidate_if":[...], "evidence_urls":["https://..."] }
  ],
  "falsified": [ { "id":"L-20260910-03", "reason":"价涨仓减连续2日" } ]
}
```

**展示层必须可见的字段**（缺一则该条逻辑不允许上首页）：
`品种 · 方向 · 驱动一句话 · 证据列表（含数值） · 确认日 · 失效条件 · 一手来源链接 · 当前状态（有效/降级/作废）`

### 6.1 用 20 日排名做因果归因的额外要求

| 要求 | 原因 |
| --- | --- |
| 必须输出 `pct_20d` 与 `pct_1d` **两个维度** | 区分"持续强势"（20日高 + 单日温和）与"突然异动"（单日飙升但20日平淡） |
| 必须输出 `rolled_over` 标记 | 20 日窗口跨换月时含跳空，是名义值，需提示 |
| 主题判定优先用 **20 日榜的板块集中度**，而非单日榜 | 20 日集中度反映资金持续流入，单日是噪声 |
| 单日榜仅作**加速度/异动警报** | 单日大幅波动可能是事件驱动（对应 L0 事件） |

## 7. 每日因果归因的信息源与可信度

> **来源不限（D4）**：下表是**推荐优先级**，不是强制接入清单。任何可用来源都可采纳，只需在输出中标注来源与可信度。

| 层级 | 来源 | 时效 | 可信度 |
| --- | --- | --- | --- |
| 一手 | 交易所官网（SHFE/CZCE/GFEX/CFFEX）：行情、**每日持仓排名**、**仓单日报**、库存周报、公告 | T 日盘后 | **最高** |
| 一手 | 统计局/海关/央行（月/旬）；发改委/工信部/能源局（政策原文） | 滞后 | 高 |
| 产业 | Mysteel/钢联、卓创、SMM：现货、基差、开工、社库 | 日/周 | 高 |
| 行情 | 东财/新浪/同花顺：快讯、盘中快照 | 实时 | 中（二手，须回溯一手） |
| 媒体 | 财联社/路透/彭博 | 秒级 | 中 |

**归因纪律**：一手（交易所/部委原文）> 行业协会 > 商业资讯 > 媒体转述。硬逻辑应尽量能落到可核验来源。

> **已实测可获取**（阶段 1 直接可用）：SHFE 每日行情 `kx*.dat`、SHFE **每日持仓排名** `pm*.dat`、CZCE 日报、GFEX 行情+仓单周报、CFFEX 行情。
> **未核实**：DCE 门户 API、INE 路径、CFFEX 排名路径、SHFE 仓单日报正确路径；文华自有字段口径（资金流/均价/Scale，官方明确不公开）。
