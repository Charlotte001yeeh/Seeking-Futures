## 1. 算法规范（已锁定）

```
20日涨跌幅 = (今日收盘价 − 基准日结算价) / 基准日结算价 × 100
```

| # | 规则 | 说明 |
| --- | --- | --- |
| **R1** | **分子 = 今日收盘价** | 盘中读取时即"最新价" |
| **R2** | **分母 = 基准日结算价** | 不是收盘价。基准日为 **T−20 = 2026-08-19** |
| **R3** | **基准日例外**：该合约 T−20 **无成交** → 基准前移到最近有成交日 | 实测：菜籽 RS611、胶合板 BB2611 均前移到 **08-18** |
| **R4** | **主力合约用 T−1 日（09-15）成交量最大者判定** | 不可用 T 日数据（会造成换月日差一天） |
| **R5** | **跨换月不拼接**：用当前主力合约自身的价格序列 | 见 §3 论证 |
| **R6** | **包含月均价期货**（`F` 后缀，DCE 的 pp/l/v） | 否则聚丙烯月均价、聚乙烯月均价缺失 |
| **R7** | **商品与金融期货混合排名** | 沪深300 IF2609 进入跌幅榜 |

### 1.1 为什么不能按"K 线条数"计数

早期版本用"该合约自身序列倒数第 20/21 条"找基准。**这是错的**——各合约 K 线序列长度不一：

- `lc2701` 在缓存序列里只有 13 条 → 锚点被推到 08-14 → 碳酸锂算成 −18.39%（正确值 −16.97%）
- 新浪的日 K 序列会**省略无成交日**（如 08-12/13/14/21 对 bb2611），导致锚点前移

**正确做法**：从官方日报建**基准日（08-19）的结算价映射**，按合约代码直接取值。

### 1.2 主力判定的 T−1 规则（关键修复）

```
main(T) = 用 T−1 日的成交量排名确定
```

**实测证据（不锈钢 ss）**：

若用 09-16 数据判定，会误判为 ss2611。

## 3. 跨换月：不拼接（实测论证）

### 3.1 窗口内确实发生了换月

对比 08-19 与 09-16 的主力合约，**17 个品种在 20 日窗口内换月**：

```
苹果   ap610 → ap701        菜油   oi611 → oi701
短纤   pf610 → pf611        菜籽   rs609 → rs611
纯苯   bz2609 → bz2610      乙二醇 eg2609 → eg2610
鸡蛋   jd2610 → jd2611      原木   lg2609 → lg2611
粳米   rr2609 → rr2610      铂     pt2610 → pt2612
纤维板 fb2610 → fb2611      纯苯   bz2609 → bz2610
国债   T/TF/TL/TS 2609 → 2612
月均价 l2701F → l2611F、pp2610F → pp2611F
```

### 3.2 但计算不需要拼接

**决定性证据 —— 菜籽 RS**：

| 方案 | 计算 | 结果 | 文华 |
| --- | --- | ---: | ---: |
| **拼接**（rs609 收 5902 → rs611 收 5414） | (5414−5902)/5902 | −8.27% | |
| **不拼接**（rs611 自身 08-18 结 5982） | (5414−5982)/5982 | **−9.50%** | **−9.50%** ✅ |

→ **必须用当前主力合约自身的价格序列。**

**原理**：文华这个字段是"当前主力合约的 20 日涨跌幅"，而非主连的 20 日涨跌幅。这也解释了为什么不能用主连数据（早期用主连算 sc/rb/cu 偏差达 −2.56/+1.55/−0.26）。

## 5. DCE 官方 API 接入（已打通）

### 5.1 认证

```
POST http://www.dce.com.cn/dceapi/cms/auth/accessToken
Header: apikey: <API_KEY>
Body:   {"secret": "<SECRET>"}
→ {"success":true,"code":200,"msg":"安全Token签发成功",
   "data":{"tokenType":"Bearer","token":"eyJ...","expiresIn":28800}}
```

Token 有效期 **28800 秒（8 小时）**。

### 5.2 取日行情

```
POST http://www.dce.com.cn/dceapi/forward/publicweb/dailystat/dayQuotes
Header: apikey, Authorization: Bearer <token>, lang: zh, tradeType: 1
Body:   {"varietyId":"all", "tradeDate":"20260916", "tradeType":"1", "lang":"zh"}
→ data[]: {variety, contractId, open, high, low, close,
           lastClear(前结算), clearPrice(结算), diff, diff1,
           volumn(成交量), openInterest, turnover}
```

### 5.3 三个坑（都踩过）

| # | 坑 | 现象 | 正确做法 |
| --- | --- | --- | --- |
| 1 | **字段名** | 用 `variety` 返回 **401「无权限访问该接口」**（易误判为无权限） | 必须用 **`varietyId`** |
| 2 | **限流** | 短时间多次调用 → `超出访问频次，已停止访问60秒` | 请求间隔 **≥2.5 秒** |
| 3 | **合约代码** | 正则 `/^[a-zA-Z]{1,2}\d{4}$/` 会漏掉月均价合约 | 用 **`/^([a-zA-Z]{1,2})(\d{4})(F?)$/`** |

### 5.4 DCE 的月均价期货（`F` 后缀）

**月均价期货**（Monthly Average Price Futures），仅三个品种：

| 品种 | 月均价合约 |
| --- | --- |
| 聚丙烯 pp | `pp2611F`、`pp2610F`、`pp2612F`… |
| 聚乙烯 l | `l2611F`、`l2610F`、`l2612F`… |
| 聚氯乙烯 v | `v2611F`、`v2610F`、`v2612F`… |

- **独立上市、可交易**，有自己的量仓（非标的合约别名）
- **结算价与标的合约一致**（`pp2611F` 结 9553 = `pp2611` 结 9553）
- 收盘价略有差异 → 20 日涨跌幅不同

**入榜情况**：`pp2611F` +16.65%（涨幅第 13）、`l2611F` +12.56%（涨幅第 17）、`v2610F` +3.98%（未入榜）

### 各源注意事项

| 源 | 注意点 |
| --- | --- |
| SHFE / INE | 剔除 `DELIVERYMONTH="小计"` 行；INE 另需剔除含"总计"的行与 `*_tas` 合约 |
| CZCE | 管道分隔；数字含千分位逗号需清洗；**GBK 编码**；剔除 `小计`/`总计` |
| GFEX | 成交量字段拼写是 **`volumn`**（官方拼错）；末行 `variety="总计"`；**接口不稳定需重试** |
| CFFEX | **CSV 无收盘价列**（列：0=合约 1=开 2=高 3=低 4=成交量 5=成交额 6=持仓 7=持仓变化 8=今结算 9=昨结算 10=前结算），故以结算价代价格 |
| DCE | 见 §5.3 三个坑 |
