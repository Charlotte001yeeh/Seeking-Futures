# 03 · 官方源免费性与"主力合约 20 日涨跌幅 rank20"口径确认

> 本轮（2026-09-16）实测与调研结论。用于回答两个决策问题：
> ① 官方源是否免费 → **是，六个交易所的每日行情/持仓排名/仓单日报均可免费直接获取。**
> ② 文华的排序是什么口径 → **主力合约报价列表（只列主力合约）实时自动排序，5 秒刷新。**

### 结论

**≥5 个交易所（SHFE/CZCE/GFEX/CFFEX + INE 待确认）的官方真值可以零成本直接抓取，无需任何授权或付费。**
DCE 需免费注册门户账号（限流），是唯一有额外门槛的。

→ **架构决策：直接采用官方源作为一档基准。** 东财/新浪降级为"盘中实时快照 + 缺口补齐 + 交叉校验"。

## 二、文华"主力合约报价"的排序口径

### 2.1 文华用什么功能实现"排序"

wh6（赢顺）提供两套排序机制：

| 机制 | 入口 | 刷新 | 快捷键 |
| --- | --- | --- | --- |
| **自动排序** | **主力合约排名 → 综合排名**（期货页面 9 宫格） | **实时 / 每 5 秒自动刷新一次** | — |
| 手动排序 | 点击报价表抬头，或快捷键 | 手动触发 | `60` 恢复原始 / **`61` 涨幅排序** / **`62` 跌幅排序** / `63`-`66` 成交量·成交额 / `67` 速涨 / `68` 速跌 |

关键事实（文华官方技术回复）：

- 自动排序**只对"主力合约"生效**——"该功能支持实时对**主力合约**、多种抬头自动排序，更方便的跟踪当天活跃品种动向"。
- 自选列表**不做**自动排序（官方解释：自选合约数目多、数据量大，不适合）。
- 排序是"点击/刷新那一瞬间的行情快照"，秒级波动会导致显示顺序看起来不完全单调——再次点击即更新。

### 2.2 对照我们的实现口径

| 维度 | 文华 | 本项目实现 | 一致性 |
| --- | --- | --- | --- |
| 排序对象 | **主力合约**（每品种一个） | 每品种取当日主力合约（按 `04 §3.2` 官方规则判定） | ✅ |
| 排序指标 | **20 日涨跌幅**（主目标 D1） | 20 日涨跌幅（**已定标**，见 `04 §3.5.5`） | ✅ **已复现（33/33 验证）** |
| 前20 | 取涨幅/跌幅头部 | 品种级排序取前 20 | ✅ |
| 刷新 | 实时 / 5 秒 | 每日收盘后一次（可加盘中模式） | ⚠️ 节奏差异，见下 |
| 流动性过滤 | **无**（官方承认"有价无市"合约可霸榜） | 双模式：`reconcile` 不过滤 / `analysis` 加阈值 | ✅ reconcile 对齐 |

### 2.3 三点必须留意的差异

1. **文华不过滤流动性**：官方承认"有些个合约成交量极其稀少，有价无市，但却占据了综合排名中涨跌幅排名榜首位置"。→ **A2 验收必须用 `reconcile` 模式（不过滤）**，否则成员必然对不上。
2. **"只取主力"已是天然过滤**：文华只排主力合约，因此我们早期实测到的 `RS709 菜籽 +13.89%`（成交 1 手）不会出现在文华榜上——这从反面印证了"每品种取主力"的必要性。
3. **实时 vs 收盘**：文华是盘中实时滚动排序；本项目是"每日同步"，需明确两种模式：
   - **盘中模式**：用东财/新浪实时快照按同口径排序，供盯盘；
   - **盘后定稿模式**：以交易所官方数据计算，作为当日正式 rank20 入库，模型只吃这一份。

## 三、对本项目设计的直接修正

| 原设计 | 修正后 |
| --- | --- |
| 东财 clist 为主源 | **交易所官方日报为主源**（免费且含结算价/持仓量）；东财仅用于盘中快照与交叉校验 |
| 涨跌幅用东财 `f3` | **用官方数据自算**（实测基准差异达 0.6pct） |
| 主力判定用成交额 | **按文华官方规则**（量+仓双料最大、维持原则），官方日报自带全月份量仓可精确判定 |
| 持仓量靠新浪 `p` 字段 | **官方日报直接给持仓量与增减量** |
| 前20净持仓列为"阶段 2" | 已实测可获取（SHFE `pm*.dat`），作为 **D4 可选增强**纳入 |

## 四、仍然待解

1. ~~**HTTPS 出口**~~ → **已解决**：根因是 curl 的 Schannel TLS 凭证故障（`SEC_E_NO_CREDENTIALS`），改用 **Node.js 通道**后全部端点 200。详见 `05`。
2. ★ **20 日涨跌幅的跨换月口径**（阻塞 A2）→ 见 `04 §3.5.2/§3.5.3`，待用户对账定标。
3. DCE 对外门户 API 的 endpoint 与鉴权（需注册免费账号）。
4. INE 独立数据路径（沿用 SHFE 路径返回 404）。
5. CFFEX 每日持仓排名的正确路径（`/sj/ccpm/...` 返回 404/302，需另找）。
6. SHFE 仓单日报路径：**原记录的 `tsite.shfe.com.cn` 域名实测 DNS 不解析（ENOTFOUND），该地址是错的**，需从 SHFE 主站重新定位。

**可行性判断**：出口已打通、官方免费源已实测可取、主力规则与当日涨跌幅口径已验证。**剩余唯一阻塞项是 20 日涨跌幅的跨换月定标。**
