## 2. 已核实结论（全部为实测，非推测）

### 2.1 数据侧

1. **【实测✅】** 东方财富 `push2.eastmoney.com/api/qt/clist/get` 可取全市场排行，`fs=m:113,m:114,m:115,m:8,m:142`，总数 **1020**；**单页上限 100，需翻 11 页**。
2. **【实测✅】** 其中**可交易合约仅 666 个，去重后品种仅 69 个**（成交额 ≥1 亿的 64 个）。这意味着"rank20"**必须做品种级聚合**（每品种取当日主力合约），否则同一品种会霸榜多个席位。
3. **【实测✅】** 东方财富日 K `push2his.eastmoney.com/api/qt/stock/kline/get?secid=113.rbm&klt=101` 可用；主连后缀为 `m`（`rbm`/`TAm`/`im`），**单合约必须小写真实月份**（`rb2610`），`rb0`/`rb2601` 返回空。
4. **【实测✅】** **东财日 K 不含持仓量**，但新浪 `stock2.finance.sina.com.cn/.../getDailyKLine?symbol=RB0` 返回 `{d,o,h,l,c,v,p,s}`，其中 **`p` 就是持仓量**，且支持主连（RB0 起点 2009-03-27）与单合约（RB2601 起点 2025-01-16）。
5. **【实测✅】** 新浪实时快照 `hq.sinajs.cn/list=nf_RB0,nf_I0,...` 支持多合约批量，可作第二源做交叉校验。
6. **【实测❌→✅】** 本机 shell 层 **HTTPS 全线不通**（curl exit 35），但**走 HTTPS 通道可以正常取到交易所官方数据**：上期所每日行情 `.../tradedata/future/dailydata/kx20260915.dat`、**每日持仓排名** `.../pm20260915.dat`，以及郑商所日报 `FutureDataDaily.txt` 均已实测 HTTP 200 取到完整内容。
   → **结论：官方"一档真值"（含结算价、持仓量、前20会员多空持仓）是拿得到的**，唯一障碍是采集进程的 HTTPS 出口需要打通（代理/证书）。这让"硬逻辑"从纸面变成可落地：`02` 文档要求的证据字段全部有官方来源。
7. **【实测❌】** 交易所旧路径已失效：`http://www.shfe.com.cn/data/dailydata/kx/kx20260915.dat` 返回 307→HTTPS 后为空/404，**必须用新路径**；INE 沿用 SHFE 路径返回 404，独立路径未核实。
8. **【调研】** 文华财经官方"历史数据服务"是按交易所计价的付费 API（K 线 3 万/年/交易所，tick+K 线 6 万/年/交易所），需 WT9 客户端在线，**只含历史不含当日**，且**授权止于"终端接收"，无再分发/对外展示权** —— 对本项目不划算。

### 2.2 分析侧

1. **硬逻辑 = 驱动 + 证据 + 确认日 + 失效条件**，四要素缺一即降级为"观察"。
2. **驱动只有四类源头**：供给冲击、需求冲击、库存/物流约束、政策与宏观。基差/月差/利润/持仓/仓单属于**传导层与验证层**，不是驱动。
3. **龙头判定禁用涨幅**，用 `LeaderScore = 0.4×持仓量分位 + 0.3×成交额分位 + 0.2×板块领先度 + 0.1×沉淀资金分位`。
4. **确认日** = 结构突破 + 量仓同步 + 板块共振 + 现货/基差同向，**满足 ≥3 条**。
5. **失效优先看两背离**：价涨仓减（空头回补）、板块涨而龙头掉队。

### 2.3 当日实测样本（可直接作为 Agent 的第一份"输入样例"）

- **涨幅共振**：能化 9 品种同向（瓶片 +4.07%、菜粕 +4.02%、甲醇 +3.83%、乙二醇 +3.05%、沥青 +3.04%、短纤 +2.83%、丁二烯胶 +2.79%、纯苯、苯乙烯）。
- **跌幅分散**：生猪 −1.72%、沪镍 −1.68%、玻璃 −1.52%、PVC −1.03%、苹果 −0.91% —— 横跨农产品与黑色建材，**无单一共振源**。
- **独立走强**：沪银 +2.20%（贵金属链条，须与能化分开归因）。

> 这张榜正好演示了框架的价值：**"能化共振"是可做多硬逻辑的候选（需验证持仓/基差），"农产品分散下跌"则不应被写成板块级做空逻辑。**

## 3. 目标架构（阶段 1 蓝图，尚未实现）

```
[采集层]  ① 交易所官方日报（SHFE kx/pm .dat、CZCE .txt、GFEX loadList、CFFEX csv）  ← 真值：结算价/持仓量/持仓排名
          ② 东财 clist（全市场快照）+ 新浪 hq.sinajs.cn（盘中快照/第二源）
          ③ 新浪 getDailyKLine（单合约日K全历史，带持仓量）
            ↓
[规范化]  可交易合约过滤 → 主力状态机（量+仓双料最大）→ 当日/20日涨跌幅 → rank20 → 三源校验 → 6 元数据字段
            ↓
[存储层]  SQLite：合约字典、日K、主力序列、涨跌幅、rank20 快照、换月事件、持仓排名、仓单
            ↓
[分析层]  板块广度 → LeaderScore → 因果链归因 → 确认日判定 → 失效跟踪   （仅针对 rank20 品种，来源不限）
            ↓
[展示层]  局域网前端（首页 rank20 双榜 + 品种日K + 题材卡片 + 逻辑看板 + 对账页）
```

**架构决策已定**：独立本地服务（Node + SQLite）+ 局域网 Web 前端。

## 5. 已确认的决策（用户已定，阶段 1 执行依据）

| # | 决策项 | 结论 | 依据 |
| --- | --- | --- | --- |
| 1 | **数据出口** | **Node.js 采集器 + 官方交易所源** | 官方源已实测免费无鉴权；curl/schannel 故障由 Node 绕过。详见 `03`/`05` |
| 2 | **主交付（D1）** | **主力合约 20 日涨跌幅 rank20**，对齐文华「主力合约报价」 | 文华该列表只列主力合约、5 秒实时排序；本项目 = 每品种取当日主力后按 20 日涨跌幅排序取前 20 |
| 3 | **幅度与 K 线（D2/D3）** | rank20 各品种的幅度数据 + 日 K 线 | 官方日报自带结算价/持仓量，可达精度要求 |
| 4 | **分析输入（D4）** | **数据来源不设限**，服务于 rank20 品种即可 | 用户明确：题材/龙头/确认日不设具体数据要求 |
| 5 | **技术形态** | **独立本地服务 + 局域网 Web 前端**（SQLite 落库） | 用户选定；展示与运维自主可控 |

### 由此确定的硬性设计约束

1. **官方源为主源，东财/新浪降级为盘中快照与交叉校验** —— 涨跌幅用官方数据自算（实测基准差 0.6pct）。
2. **主力判定必须复现文华官方规则**（量+仓双料最大、维持原则），不可沿用东财"成交量最大"口径。
3. **20 日涨跌幅必须定标后才能验收 A2** —— 公式无歧义，但"20 日前基准序列"有 5 种可能，跨换月品种才能区分。
